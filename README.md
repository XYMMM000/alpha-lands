# Alpha Lands · 量化大陆

一款以量化研究为主题的卡牌堆叠 H5 游戏：组合数据与工具、验证研究假设，在真实历史行情挑战中发现自己的研究习惯，再获得可以继续体验的学习任务。

## 🎮 在线游玩

**[点击进入游戏](https://xymmm000.github.io/alpha-lands/alpha_lands/)**

[查看两条差异化演示](https://xymmm000.github.io/alpha-lands/alpha_lands/demo.html)

支持电脑鼠标与手机触屏。存档保存在当前浏览器，换设备或清除浏览器数据不会同步存档。

## 怎么玩

1. 首次进入选择「带我玩一局」，或点击任务中的「带我完成」。
2. 拖动两张卡叠放，或依次点选它们，完成研究合成。
3. 四个目标：做出三种成果、验证一份报告、完成一次市场选择、答对一道研究题。
4. 新手训练后，完成一次真实行情研究和匹配练习，领取本轮探索指南。可复制结果；后续自由探索是可选项。

每种卡牌有稳定的身份色，补给、桌面与配方保持一致。顶部会持续提示下一步；材料不足、行动力不足时也有指引。

## 已实现

- 卡牌合成、补给、资金与行动力、回合和模拟市场事件。
- 四任务动态指引、材料定位、①② 配对、拖拽与点选操作。
- 规则画像：区分学习与自主选择；证据不足或线索冲突时保留判断；重复操作不重复增加证据。
- Panda Data 真实历史挑战：观察已见行情，提交判断后揭晓后续走势。
- 具体 QuantSkills 资源匹配，以及样本隔离、成本核查两类游戏内练习。
- 清晰的四阶段衔接与本轮结束页：保存研究倾向、行为依据和下一步指南，允许证据不足时保留判断。
- 两条独立演示路径：假设验证与风险研究。演示不读取或覆盖玩家存档。

## 本地运行与检查

游戏无需构建或安装前端依赖，直接打开 `alpha_lands/index.html` 即可。

需要使用演示页或本机 HTTP 服务时，在仓库根目录运行：

```bash
python -m http.server 8787 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8787/alpha_lands/>；演示页为 <http://127.0.0.1:8787/alpha_lands/demo.html>。

安装 Node.js 后，在仓库根目录执行逻辑检查：

```bash
node alpha_lands/check.cjs
```

检查涵盖通关、存档、四任务指引、资源不足恢复、真实数据展示隔离、画像证据、学习反馈，以及两条完整差异化路径。脚本检查不等同于实体手机或真人试玩验收。

## 数据与学习资源

历史样本来源为 Panda Data 的 `get_stock_daily`，标的 `000001.SZ`，区间为 2025-01-02 至 2025-12-31，共 243 条日线。游戏保留来源、日期、获取时间和价格口径；浏览器不需要账号或数据密钥。

- [Panda Data 接口文档](https://www.pandaaiquant.com/docs/api?api=data_overview)
- [QuantSkills：回测引擎构建与偏差规避](https://github.com/quantskills/skill-backtesting-bias-avoidance)
- [QuantSkills：回测假设核查](https://github.com/quantskills/skill-backtest-assumption-check)

QuantSkills 作为外部学习参考，对应练习为本项目原创教学情景。没有复制或执行上述仓库的回测、审计引擎。

## 边界

真实历史任务不等同于完整策略回测；卡牌合成与其他市场事件属于游戏模拟。价格变化不代表玩家收益，学习结果与研究倾向均不代表交易能力或真实风险承受能力。

静态样本在浏览器中可查看，未来信息隔离属于展示层设计，不是防作弊系统。数据样本的进一步使用和再分发应遵守来源及赛事授权。

堆叠玩法及桌面布局受到《Stacklands（堆叠大陆）》启发，未使用其游戏素材。开发过程中使用 AI 辅助代码、界面和文档制作。
